# Online Chat Application

## Project Overview

Online Chat Application is a Java-based client-server messaging application that allows multiple users to communicate over a network.

This project demonstrates fundamental Java networking concepts and the use of TCP sockets for communication.

## Technologies Used

- Java
- Socket Programming
- ServerSocket
- TCP Networking
- IntelliJ IDEA
- Git and GitHub

## Features

- Client-server communication
- Multiple client connections
- Usernames for identifying participants
- Real-time message exchange
- Message broadcasting to connected clients
- Client disconnection using the `/quit` command
